RedBus Descriptive Analytics Report

Project Overview

This project analyzes RedBus bus-ticket booking data to understand passenger trends, revenue, fares, bus preferences, and travel demand.

Objectives

- Analyze passenger and revenue growth.
- Identify customer preferences and travel trends.
- Study bus types, fares, and regional demand.
- Present key insights using descriptive analytics.

Key Findings

- Passengers increased by 17.07%.
- Gross Transaction Value (GTV) increased by 20.91%.
- Average seat price rose by 3.41%.
- Student rides increased by 26% in FY2025.
- Tier 2 and Tier 3 cities contributed 68% of origin demand.
- AC buses accounted for 67% of bookings.

Methodology

The report uses descriptive statistics, year-on-year comparisons, trend analysis, and simple forecasting scenarios based on the RedBus FY2025 report.

Tools

Excel, Python, Power BI, and document/PDF tools.

Conclusion

The analysis highlights growth in passenger demand and revenue, along with strong preferences for AC buses and increasing demand from smaller cities. These insights can support better business planning and decision-making.
